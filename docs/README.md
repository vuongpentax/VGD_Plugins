# Tài liệu

Thư mục chứa tài liệu dự án và các quyết định kiến trúc quan trọng. Hiện chưa có tài liệu cấp repo ngoài tệp hướng dẫn này; tài liệu từng plugin nằm trong thư mục plugin.

Chỉ ghi lại hành vi và quyết định thực tế khi phát triển hoặc chuyển module vào kho mã. Giữ tài liệu ngắn gọn và đồng bộ với mã nguồn.
