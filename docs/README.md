# Tài liệu

Thư mục chứa tài liệu dự án và các quyết định kiến trúc quan trọng. Tài liệu từng plugin nằm trong thư mục plugin. Tài liệu cấp repo:

- `vgd_bim/ROADMAP.md`: lộ trình phát triển VGD_BIM (cột mốc, quyết định ID, trạng thái); `vgd_bim/MASTER_PLAN.md`: kế hoạch tổng hợp gốc của chủ dự án.

Chỉ ghi lại hành vi và quyết định thực tế khi phát triển hoặc chuyển module vào kho mã. Giữ tài liệu ngắn gọn và đồng bộ với mã nguồn.
