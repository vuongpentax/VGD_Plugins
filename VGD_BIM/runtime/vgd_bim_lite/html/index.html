Dữ liệu mô hình nội thất

Cách dùng nhanh · Bắt đầu từ đâu?

Model của bạn: Chọn đồ nội thất trong SketchUp → Thông tin → chọn mẫu hạng mục → nhập mô tả tiếng Việt → Áp dụng.

Model từ đối tác: Quét mô hình → Phân loại → xem gợi ý và chỉnh thông tin → Xem trước → Xác nhận chuyển đổi.

Sau khi nhập dữ liệu: Kiểm tra → sửa các dòng báo thiếu → Xuất báo cáo → mở file trong Excel. Khu vực và tầng do bạn nhập. Plugin giữ nguyên hình học của model.
