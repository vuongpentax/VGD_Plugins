Dữ liệu mô hình nội thất

Cách dùng nhanh · Bắt đầu từ đâu?

Bóc khối lượng: Bảng khối lượng → chọn group / component trong SketchUp → bảng tự đọc → chọn preset cột → sửa Tên, Mô tả ngay trong bảng.

Model từ đối tác: Quét & xuất để xem tổng quan → Phân loại → sửa gợi ý → Xem trước → Xác nhận. Kiểm tra nằm trong tab Phân loại.

Ảnh món đồ: Bảng khối lượng → bật cột Ảnh → Cập nhật ảnh (chỉ chụp khi bạn bấm), hoặc kéo thả / dán ảnh riêng vào ô ảnh. Cỡ ảnh, góc nhìn và thư mục lưu nằm trong bảng Preset.

Xuất Excel: Quét & xuất → chọn báo cáo → lưu file CSV. Plugin giữ nguyên hình học của model.
