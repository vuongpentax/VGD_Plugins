# VGD_BIM 1.1.1

- **Giao diện gọn:** hàng tab chung hàng đầu; thanh công cụ chỉ còn nút dùng thường xuyên (Chọn cột, Tìm, Lọc, Ảnh, Nhóm theo, Tùy chọn, Công cụ); Đổi tên, Mặt trước, Loại trừ tag vào **Công cụ → Bảng**; menu Công cụ, bảng Preset và hộp Cập nhật ảnh **gập sẵn**, bấm để sổ ra; đang loại trừ tag thì có chip nhắc trên thanh công cụ; bỏ hàng nút phía dưới bảng.
- **Soạn tag gọn hơn, hiển thị tag theo scene:** tag mặc định luôn tên **Untagged** và đứng đầu danh sách (không còn hiện Layer0). Bấm chuột phải vào một tag: **Hiện ở mọi scene** / **Ẩn ở mọi scene**, mở **Loại trừ scene** để giữ nguyên tag ở scene cần giữ; scene không lưu hiển thị tag được bỏ qua và ghi rõ. Một bước hoàn tác. Lệnh ít dùng gom vào nút **Thêm ▾** và **Nhập / xuất ▾**.
- **Hút / đổ tag như Paint Bucket:** nút **Hút / đổ tag** (thay Lấy mẫu): bấm = đổ tag đang chọn, Alt + bấm = hút tag, Shift + bấm = mọi bản sao cùng component, bấm vào món đang chọn = cả lựa chọn. Trong lúc dùng SketchUp bật Color by Tag, thoát thì trả lại như trước. Mỗi lần bấm là một bước hoàn tác, bỏ qua đối tượng khóa.
- **Cây tag như Auto Tag:** nút **Tạo ▾** (tag, thư mục), nhấp đúp tên để đổi tên, chuột phải vào thư mục để hiện / ẩn theo scene, tạo bên trong hoặc **Rã thư mục**; Bật / Tắt tất cả tag hoặc thư mục; **Chế độ thu gọn**; **Danh sách loại trừ** (ẩn khỏi danh sách tag / thư mục có tên chứa từ khóa, không đổi model).
- **Sheet cho Bảng khối lượng, như Excel:** thanh sheet nằm dưới chân trang; bấm **+** để thêm sheet, bấm đúp hoặc F2 để đổi tên, bấm phải để Nhân đôi hoặc Xóa. Mỗi sheet có **cột, sắp xếp, nhóm theo, bộ lọc và tag loại trừ riêng**. Chuyển sang sheet có tag loại trừ khác thì số đo Rộng / Dài / Cao được tính lại (bảng lớn có thể mất vài giây). Sheet lưu cùng file SketchUp; file cũ tự có "Sheet1".
- **Xuất Excel / PDF đủ mọi sheet:** nhiều sheet thì file Excel có mỗi sheet một trang tính (đúng tên, cột, sắp xếp, nhóm, bộ lọc, tag loại trừ và ảnh của sheet đó), trang PDF có mỗi sheet một phần, ngắt trang giữa các sheet. Khi xuất, bảng tạm chuyển qua từng sheet rồi trả về sheet đang mở (bảng lớn có thể mất vài giây). Chỉ một sheet thì xuất như trước.
- **Cầu nối dữ liệu (nhập từ Excel / CSV):** Công cụ → Cầu nối dữ liệu: chọn file, khớp theo VGD ID hoặc Mã đối tượng, ánh xạ cột (tự gợi ý), xem trước từng giá trị rồi áp dụng trong một bước hoàn tác. Ghi tên, mô tả, xuất xứ, liên kết, quy cách, đơn giá, cột chữ tự thêm; không đổi tag, vật liệu, tầng, phòng; ô trống = không đổi. File Excel xuất từ BIM nhập lại được.
- **Nối với VGD Structure:** bảng khối lượng đọc đúng kích thước cột, dầm, tường, sàn, trần do VGD Structure dựng (thể tích, diện tích chính xác thay vì đoán từ khối bao); tầng của plugin hiện ở cột Tầng; nhóm chứa và lưới trục không thành dòng; nút **Sửa bằng plugin dựng hình**; BIM cấp VGD ID cho plugin dựng hình qua cầu nối; cửa đi, cửa sổ đếm theo cái và tường trừ lỗ cửa (từ beta.7).
- **Gợi ý nhập kiểu Excel:** gõ vài chữ đầu vào ô Tên, Mô tả, Hãng, Cỡ hoặc cột chữ thêm tay thì phần còn lại hiện mờ; Enter / Tab nhận gợi ý. Gợi ý lấy từ giá trị đã nhập trước đó (nhớ trong file SketchUp) và giá trị đang có trong bảng.
- **Cài đặt và ảnh theo từng file SketchUp:** thư mục `<tên file>_VGD_BIM` nằm cạnh file SketchUp, chứa `settings.json` (cột, sheet, tag và từ khóa loại trừ, gợi ý nhập) và ảnh. Gửi file SketchUp kèm thư mục này là người nhận có đủ ảnh, cột và tag loại trừ. File mới bắt đầu từ mặc định (đường dẫn ảnh trống, cột và tag loại trừ mặc định), không lẫn với file khác. Sửa lỗi tag loại trừ của file này hiện sang file khác.
- **Phải lưu file SketchUp trước khi chụp ảnh** (báo "Chưa lưu file SketchUp" nếu chưa lưu). Thư mục ảnh tự tạo khi chụp ảnh đầu tiên; ô Thư mục ảnh chỉ hiện đường dẫn.
- **File cũ:** lần đầu mở, BIM hỏi một lần có chuyển ảnh và cài đặt về thư mục cạnh file không (ảnh cũ ở thư mục chung không bị xóa).
- **Phòng nhiều mặt và phòng có lỗ:** chọn nhiều mặt sàn rồi tạo tất cả phòng một lần (tên theo tiền tố + số); cột và hộp kỹ thuật trong mặt sàn thành lỗ của phòng (diện tích, thể tích, chu vi tính đúng); nút **Dựng khối tất cả phòng** (một bước hoàn tác, cần VGD Room 0.1.0-beta.2 trở lên).
- Chưa có: gợi ý ở tab Thông tin và hộp Đổi tên hàng loạt; chưa quét sẵn giá trị của đối tượng cũ trong model.

Kiểm tra: tự động (test Ruby mới `dev/test_sheets.rb`, test giao diện mới `dev/test_ui_sheets.cjs`, các test cũ vẫn đạt). Chưa kiểm tra trong SketchUp thật: cần thử trên model có nhiều đối tượng (thời gian tính lại số đo khi chuyển sheet) và trên SketchUp 2022.
