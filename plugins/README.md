# Plugin SketchUp

Thư mục chứa các plugin SketchUp của VGD. Hiện chưa có mã plugin.

Chuyển từng plugin vào kho mã riêng lẻ và giữ mỗi plugin tương đối độc lập. Không tạo trước các module chưa được phát triển hoặc chuyển vào.

Phiên bản hỗ trợ tối thiểu mặc định là SketchUp 2022, trừ khi module có tài liệu quy định khác.
