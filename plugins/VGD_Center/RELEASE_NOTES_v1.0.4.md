# VGD Center 1.0.4

- Added **Cài tất cả** to Tổng quan for compatible plugins that are not installed yet.
- Added a VGD Center self-update control to Tổng quan. Center accepts stable releases only and verifies the RBZ size and SHA-256 before installing it.
- Kept plugin updates separate from installing missing plugins.
- Updated completion messages to ask users to restart SketchUp after installing Center.
