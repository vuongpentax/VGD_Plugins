# VGD Center 1.0.5

- Removed the Installed and Updates sidebar pages; each catalog card now has install/update and uninstall actions.
- Added confirmed uninstall for each installed VGD plugin, with rollback if removing its files fails.
- Moved VGD Center update controls into Settings and added the latest check timestamp.
- Added automatic stable Center update on SketchUp startup, with a persistent on/off setting.
- Added Automatic, Vietnamese, and English interface language choices.
