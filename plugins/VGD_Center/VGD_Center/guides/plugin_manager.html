VGD Plugin Manager

Bật/tắt plugin, chuyển plugin giữa các bản SketchUp và xuất gói cài đặt để mang sang máy khác.

Bật/tắt plugin

  1. Mở từ Extensions → VGD Plugin Manager hoặc nút trên toolbar, chọn tab "Bật/tắt plugin".
  2. Gạt nút của plugin để tắt hoặc bật. Plugin tắt được cất vào thư mục riêng, không bị xóa; thay đổi có hiệu lực sau khi khởi động lại SketchUp.
  3. "Tắt tất cả" và "Bật tất cả" đổi hàng loạt (có xác nhận); khi ô tìm kiếm có chữ chỉ áp cho các mục đang hiện.
  4. Lưu các plugin đã chọn thành bộ để bật/tắt cả nhóm, hoặc xuất bộ ra file để dùng trên máy khác.
  5. Hai nút "Mở thư mục Plugins" và "Mở thư mục đã tắt" mở nhanh các thư mục tương ứng.

Chuyển plugin giữa các bản SketchUp

  1. Chọn tab "Chuyển plugin", chọn bản nguồn và bản đích (mọi bản đã chạy trên máy đều có trong danh sách).
  2. Tick các plugin cần chuyển. Plugin tự sao lưu thư mục Plugins đích trước khi chép và cảnh báo cú pháp Ruby cũ có thể lỗi ở bản mới.
  3. "Xuất gói .rbz tổng" tạo một file .rbz chứa các plugin đã tick để cài ở máy khác bằng Extension Manager.

Lưu ý

Plugin cất dữ liệu bật/tắt trong thư mục VGD_PluginManager/data. Gỡ VGD Plugin Manager sẽ xóa luôn các plugin đang tắt nằm trong đó, hãy bật lại chúng trước khi gỡ. Tính năng lưu layout thanh công cụ và phím tắt đã được gỡ khỏi plugin; phím tắt dùng Import/Export có sẵn của SketchUp.

Cài đặt qua Extension Manager. VGD Plugin Manager hiện là bản beta và yêu cầu SketchUp 2022 trở lên trên Windows.
