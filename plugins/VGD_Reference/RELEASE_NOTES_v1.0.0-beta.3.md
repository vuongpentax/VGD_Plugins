# VGD Reference 1.0.0-beta.3

- Việt hóa menu Extensions, bảng quản lý, nút thao tác, nhãn trạng thái và thông báo.
- Điều chỉnh cách truyền tùy chọn texture và UV cho `View#draw2d` nhằm khắc phục trường hợp viewport chỉ hiện một màu phẳng thay vì nội dung ảnh trên SketchUp 2024.
- Cập nhật hướng dẫn cài đặt và kiểm tra bằng tiếng Việt.

Cần cài bản beta.3 và xác nhận trực quan trong SketchUp 2024 rằng ảnh JPG/PNG hiển thị đầy đủ trong viewport.
