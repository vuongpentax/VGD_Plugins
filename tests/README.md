# Kiểm thử và xác minh

Thư mục dành cho kiểm thử dùng chung toàn repo. Hiện chưa có bộ kiểm thử chung. Mỗi plugin tự có thư mục kiểm thử riêng (ví dụ `plugins/VGD_Dim/dev/`, `plugins/VGD_Cabinet/cabinet_dev/`); xem README của từng plugin để biết lệnh chạy.

Khi bổ sung kiểm thử, ghi rõ cách chạy. Phân biệt kết quả kiểm tra tự động, kiểm tra thủ công và phần chưa xác minh. Chỉ ghi nhận đã kiểm thử trong SketchUp khi thực sự thực hiện.
